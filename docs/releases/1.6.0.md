# Atlantium — versión 1.6.0

## Novedades
- Puedes abrir el panel de IA sin salir de la pantalla en la que estás.
- Antes de enviar, eliges qué contexto compartir y puedes revisar el texto; se muestra el proveedor y el tamaño aproximado.
- Tus claves de IA se guardan por proveedor; puedes borrar cada una desde Ajustes.
- Se simplifican varias pantallas y la navegación para encontrar mejor las secciones.
- El temporizador de concentración continúa al cambiar de pantalla y la pizarra se puede crear desde su diálogo.

## Avisos
- Para usar un proveedor remoto, configura tu propia clave en Ajustes. Desde el panel, solo se envía el contexto que elijas al proveedor mostrado.
- El instalador de Windows no está firmado y puede mostrar un aviso de seguridad; el instalador para Mac todavía no se ha probado.
